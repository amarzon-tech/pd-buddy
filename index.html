      Limits of the estimate

      • Every number here is a model estimate, not measured. The Garred simple diffusion model fitted to one PET has not been validated as a prescribing model.
      • Ultrafiltration is not predicted. UF counts only when you enter it.
      • It ignores residual volume, fill-volume and posture effects on transport, and CCPD fill/drain time.
      • Transport type alone uses typical values for that type (Twardowski bands), not the patient’s own membrane. Kt/V needs a measured 4-h D/P urea.
      • Urine volume alone is not converted to clearance; residual function counts only with urine and serum urea (and creatinine for CrCl).
      • Icodextrin (Extraneal) kinetics are not modeled.
      • ISPD 2020: “There is no specific clearance target that guarantees sufficient dialysis for an individual.” Confirm any change with a measured 24-h dialysate and urine collection.
